# wwwPREZENTACE – ukázka webu SVJ s wiki (jen pro prezentaci)

Otevřete **index.html** v prohlížeči (dvojklik). Funguje bez internetu i bez serveru.

- **index.html** – web SVJ podle verze AA (historie domu bez jmen).
- Tlačítko **Průvodce pro vlastníky** otevře ukázku veřejné části wiki (`wiki/start.html`).
- Odkaz **Přihlášení pro výbor** v patičce otevře ukázkovou přihlašovací stránku (nefunguje, je jen na oko).
- Stránky wiki jsou vytvořené z připravených textů ve složce `wiki-stranky-SVJ/pages/vlastnici`
  a vzhledem napodobují DokuWiki. Místa, která ještě nejsou doplněná (FIXME), jsou označená štítkem „doplníme“.

**Tuto složku nenahrávejte na server.** Na server patří obsah složky `www-verze-D`; wiki bude skutečná DokuWiki.
